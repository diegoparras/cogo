# Code of Conduct

## The short version

Be decent. Assume the other person is trying to help.

## What's expected

- **Criticize the code, not the person.** "This breaks when the vault is empty" is useful.
  "This is amateur work" is not, and it's usually wrong anyway.
- **Say what you actually verified.** If you're guessing, say you're guessing. This is a
  project about not claiming more than you can hold up; it would be strange to run it any
  other way.
- **Accept a "no" without relitigating it.** COGO deliberately refuses to do many things.
  If a feature is turned down, you're welcome to fork — that's what the MIT license is for.
- **Nobody owes you a reply.** This is maintained by one person in their own time. A stale
  issue is not an insult.

## What's not acceptable

Harassment, insults, or personal attacks. Discrimination or demeaning comments based on
someone's identity — including but not limited to gender, gender identity, sexual
orientation, disability, physical appearance, body size, ethnicity, nationality, age, or
religion. Publishing someone's private information. Sustained disruption of discussions.

None of this is negotiable, and none of it becomes acceptable because the technical point
underneath it happened to be correct.

## Scope

This applies in issues, pull requests, commit messages, discussions, and anywhere else
someone is representing this project.

## Enforcement

Report anything to **diegoparras@gmail.com**. Reports stay private.

I'll look into it and act — that can mean asking someone to edit a comment, removing
content, or blocking an account. I'm one person, not a committee, so decisions will be mine
and I'll explain them if asked.

---

This is a plain-language code of conduct rather than a long template. If you'd rather read
the standard version, the [Contributor Covenant](https://www.contributor-covenant.org/) says
substantially the same things at more length, and nothing here is meant to contradict it.
